# Lego-ALMA
Code for the Lego-ALMA model in Cologne

## Projekt auf GitHub hochladen (inkl. Anleitung)

Wenn dein Projekt lokal auf dem Computer liegt und du es zusammen mit dieser Anleitung auf GitHub hochladen möchtest, gehe so vor:

1. **Neues Repository auf GitHub erstellen**
   - Öffne GitHub und erstelle ein neues Repository (z. B. `Lego-ALMA`).
   - Kopiere die Repository-URL (HTTPS oder SSH).

2. **Im Projektordner Terminal öffnen**
   ```bash
   cd /pfad/zu/deinem/projekt
   ```

3. **Git initialisieren (falls noch nicht passiert)**
   ```bash
   git init
   ```

4. **Dateien hinzufügen und committen**
   ```bash
   git add .
   git commit -m "Initial commit: Projekt mit Anleitung"
   ```

5. **Remote setzen und auf GitHub pushen**
   ```bash
   git branch -M main
   git remote add origin <DEINE_GITHUB_REPO_URL>
   git push -u origin main
   ```

Danach ist dein Projekt inklusive README/Anleitung auf GitHub verfügbar.
